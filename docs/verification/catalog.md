## 图片元数据实现

官方 SDK 的文件信息读取在当前私有存储环境未能提供有效元数据；最终实现使用官方 getTempFileURL 的 COS_URL 地址，Node HTTPS 单字节 GET Range，206 读取 Content-Range 总大小，200 读取 Content-Length。限定 HTTPS 云存储域名、不跟随跳转、8 秒超时；关闭响应体，不完整下载文件，不输出地址/签名。测试覆盖无完整大小、403、非平台 URL 等拒绝路径，技术方案 4.7.5 已同步到 r848。
