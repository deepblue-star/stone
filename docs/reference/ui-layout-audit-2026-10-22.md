## 2. 页面层级和主路径

```text
首页
├─ 设计手串 → DIY起始页
├─ 好物 → 好物分类页
└─ 客服

好物 → 分类 / 搜索 → 商品列表 → 商品详情
                                  ├─ 加入购物车
                                  └─ 立即购买 → 确认订单

DIY起始页
├─ 最近设计 → 继续设计 → 编辑器
├─ 更多 → 我的设计列表 → 固定版本详情 / 历史版本
└─ 手串定制 → 新设计编辑器

我的
├─ 邀请码卡 → 复制 / 邀请记录与分享
├─ 优惠券 → 可用券 → DIY使用
├─ 积分与兑换 → 签到 / 积分明细 / 积分商城
├─ 购物车 → 勾选条目 → 确认订单
├─ 我的订单 → 状态筛选 → 订单详情
├─ 收货地址 → 新增 / 编辑 / 默认 / 删除
├─ 客服
└─ 条款和条件

确认订单 → 选择地址、核对金额 → 提交订单 → 微信支付 → 订单详情
```

四个 Tab 使用页级切换；商品列表、详情、编辑器等二级页面保留返回关系。地址选择应返回原确认订单，而不是跳回“我的”。保存设计与提交订单是不同操作。

## 4. DIY 编辑器的固定分区

```text
导航 / 返回
预计价、周长或珠子数量提示
────────────────────────
             手串画布
────────────────────────
功能    保存             完成设计
────────────────────────
材料切换 / 搜索
左侧分类       │ 右侧三列 SKU
兑换券         │ 图片 + 免费数量角标
正在使用       │ 名称、尺寸、价格
真实材料分类   │ 可滚动选择
```

依据：PRD 3.1.2、技术方案 5.2.1 和 5.2.1.1、汇报方案 2.3。

- 画布与材料面板同屏，不能通过页面切换才能添加材料。
- 添加、删除、重排后，画布、周长提示、预计价和本设计剩余免费数量同步更新。
- “兑换券”按 SKU 聚合去重，显示本设计剩余数量；普通分类也显示免费角标。
- 本设计用完某 SKU 免费数后，该 SKU 在兑换券筛选消失；删除对应材料后重新出现。普通分类仍可按当前价格继续添加。
- 保存/切换设计不消耗券。其他设计可以各自预估同一权益；订单对本次全部项目统一分配券，避免重复抵扣。
- 待付款占用或已核销的券不计入可用数。重新打开历史设计须重新读取当前材料和券，而不是把旧预计价当作固定价格。
- 保存留在编辑流程并给予结果反馈；完成设计承接保存后的购买流程。现有“保存后跳设计详情”的中间路径并无完整截图证明，不能将其写成对标的既定行为。

## 6. 尚未由文档固定的细节

1. 完成设计后是设计购买预览、详情还是直接确认订单，现有文档仅要求承接购买；不得把当前代码的跳转反向当成需求依据。
2. “我的设计”完整列表和设计详情的具体版式未有充分视觉稿。已明确的是固定版本、历史、复制、编辑和购买能力；整体预览的位置不能冒称已有截图规定。
3. 积分中心正文和明细/商城拟稿分别提供不同层级信息，不能因此随意合并或增加多余必经页。
4. 购物车预览要求地址，而用户可能没有地址。后续应结合现有接口确定缺地址状态，不得为了显示总价伪造运费，也不得擅自新增强制跳转。
