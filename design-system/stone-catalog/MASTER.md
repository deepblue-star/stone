# Stone 商品目录设计规范

依据：技术方案 r847 / PRD r733；现有 Vue 3 管理端和原生 Skyline 小程序。本文是本项目的人工综合设计决策，不是未命中检索结果的原样持久化。

## 目标与视觉方向

让商家能判断“编辑的是商品还是具体规格”，让用户能判断“选中了什么规格、多少钱、有无库存”。方向为 Organic/natural，自然材质目录；不使用营销页 Hero、虚构统计或无意义图表。

## 设计变量

- 主色 #285C4D；背景 #F7F6F2；内容表面 #FFFFFF；正文 #20372F；辅助文字 #58655E；边框 #D7DFD8；危险 #A62F2F。
- 中文字体 Microsoft YaHei、PingFang SC；标题可用 Georgia 的英文字标。只用本地字体，不引入外网字体请求。
- 4/8 间距，表单纵向间距 20–24px；触控目标至少 44px；文字 14–16px，移动端正文 16px。
- 色彩和状态同时提供文字说明。默认浅色；不额外承诺未测试的深色主题。

## 页面结构

- Web：窄侧导航与商品工作区形成不等宽布局；目录类型、分类与列表筛选分层。编辑以分组表单展示公共资料、规格定义和具体 SKU；库存单独调整，避免普通保存覆盖库存。
- 小程序：大图片与精确价格/规格信息，分类标签可滚动；详情按 spec_schema 的 label/options 渲染，缺货项禁用并说明。
- 信息密度服务日常编辑，不为审美打断表格/表单的阅读顺序。

## 交互与可访问性

- 请求中禁用对应按钮并显示操作名称；失败保留输入；不以固定延时恢复。
- 表单使用可见标签，错误紧邻字段，通过 aria-describedby 关联；多错误时顶部聚焦摘要并定位字段。
- 弹窗保留键盘焦点、Esc 关闭、返回原触发点；提交中不允许误关闭。
- 下架/删除先展示真实预占和退分影响；存在预占时确认按钮禁用，不使用静默批量删除。
- 图片保持固定比例、懒加载、失败回退；示例生成图明确标识，不能冒充真实商品。
- 仅使用 Lucide 图标；有文本的装饰图标 aria-hidden；只含图标的按钮须有名称。
- CSS 反馈约 150ms，尊重 prefers-reduced-motion；无自动轮播和拖拽唯一入口。

## Skill 采用说明

ui-ux-pro-max 的两次 design-system 搜索分别返回营销型、药店型建议，产品匹配不成立，未持久化其配色/布局。已采用精确 ux 搜索命中的 Focusable Error Summary、Error Messages、Error Placement。Vue 栈建议在复杂表单使用验证库；本期共享验证模型集中定义，避免每个输入各写一套规则，后续复杂度增加再评估依赖。
